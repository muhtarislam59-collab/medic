# 👁️ «Торлы қабық·ЖИ» — сайт со статьями о болезнях + ЖИ-чат (Gemini API)

Сайт на казахском языке (только мобильная версия) по теме:

> **Қант диабеті кезіндегі торлы қабықтың нейрофизиологиялық қызметінің өзгерістері**
> (Бүйрек ауруларындағы көз өзгерістерін ЖИ негізінде визуалды талдау)

## 🚀 Запуск

1. Установите Node.js версии **18+** (пакеты дополнительно ставить не нужно).
2. Вставьте свой ключ Gemini API в файл **`.env`**:

   ```
   GEMINI_API_KEY=ваш_ключ_здесь
   ```

   (ключ можно бесплатно получить на https://aistudio.google.com/app/apikey)
3. Запустите сервер:

   ```
   node server.js
   ```

   или `npm start`.
4. Откройте в браузере: **http://localhost:3000**

## ☁️ Деплой на Render

В корне проекта добавлен `render.yaml` с настройками Node.js Web Service и проверкой `/health`.

1. Создайте приватный GitHub-репозиторий и загрузите туда проект. Не добавляйте `.env` и не публикуйте API-ключ.
2. В Render выберите **New → Blueprint**, подключите GitHub-репозиторий и подтвердите конфигурацию из `render.yaml`.
3. В переменные окружения сервиса добавьте `GEMINI_API_KEY` и значение `GEMINI_MODEL` с названием модели, доступной вашему Gemini API-ключу.
4. После успешной сборки откройте выданный Render URL. Проверка сервера: `https://<ваш-домен>/health`.

Render передаёт порт через `PORT`; сервер использует его автоматически. Чат не заработает без корректных `GEMINI_API_KEY` и `GEMINI_MODEL`, но статические страницы будут открываться.

## 🤖 Как работает чат-бот с ограничением темы

1. Сообщение пользователя уходит на `/api/chat` сервера (`server.js`), сервер скрыто вызывает Gemini.
2. Ответ приходит **в реальном времени (streaming)**: сервер открывает поток `streamGenerateContent?alt=sse`,
   и текст «дописывается» на экране по мере генерации, как в ChatGPT (с мигающим курсором `▍`).
3. Модели передаётся **системная инструкция** (константа `SYSTEM_PROMPT` в `server.js`):
   - отвечать **только** на вопросы по двум темам (ретина при диабете, ЖИ-анализ глаз при болезнях почек);
   - отвечать всегда **на казахском**;
   - если вопрос посторонний — писать в начале ответа маркер `[ОТАҚЫ ТАҚЫРЫП]`.
4. Сервер перехватывает первый фрагмент потока: если он начинается с маркера — пользователю отправляется **детерминированный отказ** с подсказкой правильных тем, а сырой текст модели клиенту не показывается.
5. В интерфейсе чата есть кнопка-самопроверка «🚫 Сынақ: басқа тақырып» — нажмите её, чтобы увидеть отказ бота на постороннем вопросе.

Дополнительно: ввод врача-дисклеймера («не является медицинской консультацией»), лимит сообщений (rate limit), история диалога, авто-перебор моделей (по списку `GEMINI_MODEL`) и резервный доступ через DNS-over-HTTPS, если системный DNS не работает.

## ⚙️ Переменные `.env`

| Переменная | Описание | По умолчанию |
|---|---|---|
| `GEMINI_API_KEY` | Ключ Google Gemini API | — (обязательно) |
| `PORT` | Порт сервера | `3000` |
| `GEMINI_MODEL` | Модель (можно перечислить несколько через запятую — будет перебор) | `gemini-3.5-flash-lite,gemini-3.5-flash,gemini-2.5-flash` |
